# Oracle Enterprise Manager Agent Upgrade – 13.4 to 13.5

## Overview

This documents the upgrade of a standalone Oracle Enterprise Manager Management Agent from version 13.4 to 13.5 using the Enterprise Manager Cloud Control console.

It provides a practical, step-by-step reference for database administrators and infrastructure engineers performing Management Agent upgrades.

## Scope

| Item | Description |
|---|---|
| Component | Oracle Management Agent |
| Source version | OEM Agent 13.4 |
| Target version | OEM Agent 13.5 |
| Deployment type | Standalone |
| Upgrade scope | Single agent |
| Upgrade method | OEM Console |

## Objectives

- Explain the OEM Management Agent upgrade process.
- Document pre-upgrade readiness checks.
- Demonstrate the upgrade workflow through OEM Console.
- Provide post-upgrade validation steps.
- Capture common issues and troubleshooting guidance.

## Contents

- Pre-upgrade checks
- Agent software availability

- Post-upgrade validation
- Troubleshooting
